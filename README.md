# دعوة زفاف عبدالله باجري ونور باوزير

دعوة زفاف عربية تفاعلية ببطاقة مطوية: تبدأ بمغلف مغلق، ثم تنفتح إلى كتيّب من صفحتين على الشاشات الكبيرة، وإلى مسار عمودي متصل على الهاتف يجمع بطاقة الدعوة ثم تفاصيل الحفل أسفلها. التنفيذ ثابت وخفيف باستخدام HTML وCSS وJavaScript ES modules دون إطار عمل أو خادم خلفي.

## بيانات المناسبة الحالية

| البيان | القيمة |
|---|---|
| العريس | عبدالله باجري |
| العروس | نور باوزير |
| التاريخ | الثلاثاء ٢٤ نوفمبر ٢٠٢٦ (`2026-11-24`) |
| الوقت | ٨:٠٠ مساءً |
| المنطقة الزمنية | `Asia/Aden` — التوقيت المحلي في اليمن |
| القاعة | صالة الزين |
| الموقع | اليمن |
| رابط الخريطة | [Google Maps](https://maps.app.goo.gl/ybWj4f9NkbEFLaZQ6?g_st=iw) |
| الوضع التجريبي | متوقف (`demoMode: false`) |

كل البيانات القابلة للتعديل موجودة في `js/config.js`.

## التشغيل المحلي

شغّل خادم ملفات ثابتة من مجلد المشروع؛ لا تفتح `index.html` مباشرة عبر `file://` لأن وحدات JavaScript تحتاج إلى HTTP.

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`. لا يوجد تثبيت حزم أو أمر بناء.

## تحديث بيانات المناسبة

عدّل القيم في `js/config.js` فقط، مع إبقاء التاريخ بصيغة `YYYY-MM-DD` والوقت بصيغة 24 ساعة `HH:MM`:

```js
export const wedding = {
  groomName: 'عبدالله باجري',
  brideName: 'نور باوزير',
  eventDate: '2026-11-24',
  eventTime: '20:00',
  timeZone: 'Asia/Aden',
  city: 'اليمن',
  venueName: 'صالة الزين',
  venueAddress: 'اليمن',
  mapsUrl: 'https://maps.app.goo.gl/ybWj4f9NkbEFLaZQ6?g_st=iw',
  calendarDurationMinutes: 180,
  demoMode: false,
};
```

`invitationMessage` و`shareTitle` و`shareDescription` و`calendarFileName` موجودة في الملف نفسه. مدة التقويم الحالية `180` دقيقة هي قيمة قابلة للتعديل؛ غيّرها إذا تم تأكيد مدة مختلفة.

## العدّ التنازلي والتقويم والخريطة والمشاركة

- العدّ التنازلي يستخدم الثلاثاء ٢٤ نوفمبر ٢٠٢٦، الساعة ٨:٠٠ مساءً بتوقيت اليمن (`Asia/Aden`) ويحدّث الأيام والساعات والدقائق والثواني كل ثانية. بعد بداية المناسبة تظهر عبارة تهنئة عربية.
- يظهر موقع القاعة «صالة الزين — اليمن»، ويفتح زر الموقع رابط Google Maps المحدد في الإعدادات في نافذة جديدة آمنة.
- ملف `.ics` يستخدم `DTSTART;TZID=Asia/Aden:20261124T200000` والموقع ومدة التقويم المضبوطة في `calendarDurationMinutes`.
- المشاركة تستخدم `navigator.share()` عند توفره، وإلا تنسخ رابط الصفحة الحالي مع رسالة عربية.
- لا تعمل الدعوة على الفتح تلقائيًا: يلزم الضغط على المغلف أو زر الفتح. يعمل `Escape` للفتح الفوري، ويحترم التصميم تفضيل تقليل الحركة.

## مزامنة البيانات الوصفية وصورة واتساب

روبوتات معاينة الروابط لا تشغّل JavaScript، لذلك تحتوي `index.html` و`site.webmanifest` و`assets/og-source.html` على نسخ ثابتة من بيانات المناسبة. بعد تعديل `js/config.js` شغّل:

```bash
node tools/sync-static.mjs
```

لتحديث العنوان والوصف وروابط Open Graph وTwitter والبديل النصي وبيانات manifest ونص بطاقة المشاركة. ضع عنوان النشر النهائي في `site.url` داخل `js/config.js` قبل النشر؛ إذا بقي فارغًا ستظهر روابط `https://your-domain.example/` التحذيرية، ولا ينبغي نشرها كما هي.

بعد المزامنة أعد توليد `assets/og-image.png` من `assets/og-source.html` بمقاس **1200×630** وانتظر تحميل الخطوط العربية. الخطوات التفصيلية في `assets/README.md`. انشر عبر HTTPS واختبر معاينة الرابط الفعلية في واتساب؛ لا يمكن اختبار روبوت واتساب دون نطاق منشور.

## النشر

ارفع المجلد كما هو إلى Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages أو أي استضافة ملفات ثابتة. حافظ على المجلدات `assets/` و`css/` و`js/` و`tools/`، واجعل `index.html` في جذر الموقع. لا توجد إعدادات بناء أو إعادة توجيه مطلوبة.

## التحقق

تم تشغيل الموقع على خادم محلي وفحصه في Microsoft Edge headless عند المقاسات **320×568، 360×640، 375×667، 390×844، 430×932، 768×1024، و1440×900**. شمل الفحص ترتيب الصفحتين على سطح المكتب، المسار العمودي وسهم الانتقال إلى «تفاصيل الحفل» على الهاتف، ظهور السهم وتسمية «تفاصيل الحفل» معًا، التمرير السلس، الحركة المرحلية للمغلف، تحديث العدّ التنازلي، ملف التقويم، رابط الخريطة، المشاركة، لوحة المفاتيح، تقليل الحركة، وحالة انتهاء المناسبة. لم يظهر تمرير أفقي أو أخطاء في وحدة التحكم.

لم يتم اختبار هاتف فعلي أو متصفح واتساب المضمّن؛ يُنصح بذلك بعد النشر. كما أن فحص معاينة الرابط يحتاج إلى النطاق النهائي.
